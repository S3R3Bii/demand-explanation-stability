# Sources, rights and method context

1. Hadi Fanaee-T (2013), **Bike Sharing**, UCI Machine Learning Repository, DOI [10.24432/C5W894](https://doi.org/10.24432/C5W894). [Official dataset and current CC BY 4.0 terms](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset). [Official archive](https://archive.ics.uci.edu/static/public/275/bike%2Bsharing%2Bdataset.zip). The data are hourly/daily Capital Bikeshare counts and weather from 2011–2012. This package uses the original hourly file, retaining attribution and the row-count discrepancy. It adds timestamps, lossless numeric serialization, transformations, models, results and figures. No endorsement is implied. Archive/member/panel hashes and original retrieval time are in `data/manifest.json`; the raw archive is not committed. No source paper is redistributed.

2. Aaron Fisher, Cynthia Rudin and Francesca Dominici (2019), **All Models are Wrong, but Many are Useful: Learning a Variable's Importance by Studying an Entire Class of Prediction Models Simultaneously**, JMLR 20(177), 1–81. [Primary article](https://www.jmlr.org/papers/v20/18-760.html). The paper establishes that variable importance can vary across models and develops model class reliance. This study is a bounded comparison of whole-week refits and stratified permutations. It does not reproduce the article's estimator, bounds or full model-class search, and does not claim the idea is novel.

3. scikit-learn, **Permutation Importance with Multicollinear or Correlated Features**, [official 1.7-series example](https://scikit-learn.org/1.7/auto_examples/inspection/plot_permutation_importance_multicollinear.html). Related measurements can obscure interpretation of individual importance. This study retains separate and joint-temperature results, with explicit limits on what the shuffles preserve. Runtime scikit-learn is pinned at 1.7.0; the maintained 1.7 documentation page currently identifies 1.7.2.

Code uses ridge regression, cubic splines, CART and histogram gradient boosting from the pinned scientific stack. Defaults not overridden in the protocol remain inherited library choices. Finite grids, fixed iterations, source-normalization limits, group resampling and clipping are declared before fitting. No literature-wide novelty, causal identification or production validation is asserted.
